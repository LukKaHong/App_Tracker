# 宠物定位器功能需求V1.0

## 1.工作模式

| 工作模式 | 联网                                                         | 定位频率                                   | 说明                                                         |
| -------- | ------------------------------------------------------------ | ------------------------------------------ | ------------------------------------------------------------ |
| 寻宠模式 | 保持mqtt连接，周期上报数据                                   | 10秒/次                                    | 1、通过平台下发指令进入此模式，进入此模式10分钟后自动切回到看护模式，避免长时间耗电。 |
| 遛宠模式 | 保持mqtt连接，周期上报数据                                   | 30秒/次                                    | 1、通过平台下发指令进入此模式，进入此模式30分钟后自动切回到看护模式，避免长时间耗电。<br /> |
| 看护模式 | 保持mqtt连接，周期上报数据                                   | 5分/次                                     | 1、在关机模式下，长按按键5秒可进入此模式。<br />2、可通过平台下发指令进入此模式。 |
| 省电模式 | 保持mqtt连接，周期上报数据                                   | 1小时/次                                   | 1、可通过平台下发指令进入此模式。                            |
| 休眠模式 | 保持mqtt连接，不主动上报数据，收到平台的状态读取指令后上报数据 | 收到平台的状态读取指令后，才会进行一次定位 | 1、可通过平台下发指令进入此模式。<br />2、处于超低电量的时候，上报一次状态事件，上报完成后强制切换到休眠模式。<br />3、只有收到平台的状态读取指令后，才会进行一次定位，定位完成之后关闭定位功能，然后上报一次数据给平台。 |
| 关机模式 | 不进行联网                                                   | 不进行定位                                 | 1、装上电池、复位后默认为此模式。<br />2、在非关机模式下，长按按键5秒可进入此模式。 |



| 步骤  | 说明                                                         |
| ----- | ------------------------------------------------------------ |
| step1 | 根据定位频率设置RTC闹钟唤醒。                                |
| step2 | 模组设置成LP模式，关闭GNSS电路电源。                         |
| step3 | 等待闹钟唤醒。                                               |
| step4 | 1、打开GNSS电路电源，读取GNSS芯片的定位信息。<br />2、断开mqtt连接，进行wifi scan，获取wifi热点参数后恢复mqtt连接。<br />3、进行LBS定位，获取基站参数。 |
| step5 | 1、等待GNSS、WIFI和LBS定位完成。<br />2、所有定位完成后跳转step6（2分钟超时）。 |
| step6 | 上报数据给平台，跳转step1                                    |



## 2.定位功能

定位频率根据运行模式调整。

### 2.1 GNSS

定位需要获取当前的经纬度、卫星连接数、移动速度。

定位芯片型号为CC1161W，协议为NMEA 0183，使用串口进行通讯，波特率115200，8位数据位，1位停止位，无奇偶校验。

定位芯片的波特率要设置成跟串口波特率一样，一直尝试设置，尝试设置间隔为2秒，直到设置好为止。

### 2.2 LBS & WIFI定位

定位器获取原始的基站参数+WIFI热点参数上报给平台，平台再通过高德进行坐标解算。定位器不通过高德进行坐标解算，只上报参数给平台。

基站参数：

| 字段   | 含义                     |
| :----- | :----------------------- |
| mcc    | 移动国家码               |
| mnc    | 移动网络号               |
| lac    | 位置区码（LTE 下即 TAC） |
| cellid | 小区编号（LTE 下即 ECI） |
| signal | 信号强度，**负数 dBm**   |

WIFI热点参数：

| 字段   | 含义                     |
| :----- | :----------------------- |
| mac    | AP 的 MAC 地址，冒号分隔 |
| signal | RSSI，负数 dBm           |
| ssid   | 热点名称                 |

详细的参数信息查阅高德智能硬件定位方法：https://lbs.amap.com/api/webservice/guide/api-advanced/hardware-location

## 3.按键功能

一颗按键，实现开关机模式的切换。

在关机模式下，长按5秒切换到开机模式-正常模式，且蜂鸣器响两声。

在开机模式下，长按5秒切换到关机模式，且蜂鸣器响一声。

软件使用中断方式实现，当主控处于低功耗休眠模式时，需要实现IO唤醒。

## 4.蜂鸣器功能

接收到平台下发的声音启动指令后，蜂鸣器每一秒响一次，持续时间由平台下发，如持续时间内收到停止指令，停止蜂鸣。

## 5.指示灯

接收到平台下发的指示灯启动指令后，持续快闪，持续时间由平台下发，如持续时间内收到停止指令，停止快闪。

## 6.联网功能

### 6.1离线重连

在非关机模式下，需一直与平台保持连接，如遇到断线情况，反复尝试重连。

### 6.2离线补传

与平台断开连接后，需要缓存上报给平台的数据，与平台恢复连接后，要补传离线期间的数据，缓存的数据最大条数为30，当数据条数大于最大条数时，删除最早的数据。

离线数据重启定位器后可丢失，不做落盘处理。

### 6.3OTA功能

支持ML307固件远程更新，使用全系统差分升级方案。

### 6.4平台协议

按《DEVICE\_CLOUD\_PROTOCOL.md》实现。

按《HARDWARE_COMMAND_INTEGRATION.md》实现。

## 7.电量计算

通过电池电压估算SOC，通过主控的ADC检查电压。

SOC小于20%为低电量状态。

SOC小于5%为超低电量状态。

| 电池 ADC     | Pin9  | 电量检测。                                            |
| GPS UART1_RX | Pin28 | GPS芯片通讯。                                         |
| GPS UART1_TX | Pin29 | GPS芯片通讯。                                         |
| DBG_RX       | Pin38 | log串口。                                             |
| DBG_TX       | Pin39 | log串口。                                             |
